第三节_耐心:得耐心者得天下_整理

天道

  1. 复利曲线
    价值积累前期极慢, 过了拐点飞速爆发, 量变引起质变
    付出不是即时得到回报, 专注自身发展, 每天的一点点进步, 都在给未来的爆发汲取养分

  2. 舒适区理论
    能力分布为舒适区 -> 拉伸区 -> 困难区, 最佳成长位在舒适区边缘的拉伸区
    冲进困难区会受挫, 缩在舒适区会停滞, 面对未知感到害怕的同时又有点兴奋, 那就是踩中拉伸区的信号, 突破就是在这里发生的

  3. 成长权重
    价值权重为改变量 -> 行动量 -> 思考量 -> 学习量
    买书不拆等于学会是表层学习量的自嗨, 学得多不如改得真, 读书不求全记住, 哪怕只有一个观点让我们内化于心以及外化于行, 我们已经赢太多了, Less is more

  4. 学习曲线
    学习不是线性的, 而是波浪式的, 付出努力却毫无进步的平台期是大脑在后台偷偷重建数据库以及巩固神经元
    遇到瓶颈不是太笨, 是大脑在加载, 在平台期多熬哪怕一个月, 我们就能破土而出, 现在放弃, 之前的努力全部清零

谈判
理智脑负责做决策, 本能脑和情绪脑负责出劳动力, 想让他们干活得靠利益交换

  1. 非暴力沟通, 接纳急躁天性
    发现自己焦虑或者想玩手机时别自责, 温和地对体内的小家伙说, 你看, 又急, 理解理解, 培养耐心的第一步是允许自己偶尔没有耐心, 宽限容错才能长久

  2. 利益交换, 实行后娱乐机制
    别逼自己戒断手机, 跟大脑谈判, 我们的小宝宝拒绝放弃享受, 但能接受延迟享受, 把娱乐变成完成任务后的最高犒赏, 让大脑尝到甜头, 它就会对这种先苦后超爽的模式上瘾

  3. 意义赋予, 把困难变成游戏
    拒绝做任何毫无意义以及过程坐牢的事, 主动去探索原理, 赋予行动高维度的意义, 利用好我们的本能, 科学家和跑步狂热者不是靠意志力死撑, 而是他们的理智脑成功让本能脑觉得解方程和跑步简直太好玩了, 只要把克服困难拆解成游戏通关, 本能脑就会主动冲上去
